The `reset_point_search` step runs as a `ResetPointSearchNode`, a port of the experimentalists' reset-point-search calibration script (QHC-1807). It moves the qubit line into the tree's `[target_freq_min, target_freq_max]` window (required, no default) by stepping the flux and re-measuring, then writes the reset point's absolute `flux.z` and drive IF (ADR-0011). The crosstalk matrix is left alone.

- Each measurement is the shared `two_tone_saturation` QProgram from `qili-qprograms` (QHC-1916), run through the new `TwoToneSaturationNode` spine. The spine sets the operating point's hardware with `_set_operating_point_hardware` and streams with `_stream`. Its drive level defaults to `drive_power` -40 dBm for a Rohde & Schwarz source and `drive_gain` 1 for a QCM-RF, as in the legacy two-tone node.
- The node runs at the step's `operating_point` (QHC-1936): it searches from that point's flux and writes that point.
- A rejected fit widens the span (the `drive_if_sweep` window, then 30 MHz, then 60 MHz). The flux steps are a probe, then a secant clipped to the maximum step. The node waits `flux_settle_duration` (ns) after placing the point, before the first sweep, and after each move, as the script does. The step fails after the move limit.
- A `drive_if_sweep` that starts and stops at the same value, a missing target window, or a `target_freq_min` not below `target_freq_max` fails the target before anything is measured. `_sweep` rejects the first for every node. A retry span no wider than the sweep before it is skipped.
- `LorentzianPeakModel` fits the two-tone line's rotated quadrature. It accepts a fit only if R² ≥ the step's `min_r2` and the sweep step < linewidth < span. It saves `drive_if` and `fit_r2` to the measurement entry, and each sweep's plot to its own file, named with the measurement id.
- One Lorentzian fit (QHC-1932 item 5): `FittingClass.fit_lorentzian` is a bounded local least-squares fit started from `FittingClass.lorentzian_initial_guess`, which reads the baseline, centre, height and width off the trace. `LorentzianPeakModel`, `two_tone_vs_flux` (through `lorentzian_fit`) and the legacy two-tone fit all use it. It fits from a peak and from a dip and keeps the higher R², so a line near the window's edge, which pulls the edge baseline, is still found. A fit that did not converge is dropped, and so is one whose centre is within one sample spacing of either end of the window: the centre is bounded to the window, so a line just outside it would otherwise fit with its centre pinned on the edge. It replaces `lorentzian_fit`'s `differential_evolution` fit, which reported the grid point at the fitted extremum, and the script's start, whose width came from the stored IF and was zero for an IF of 0. The fit is deterministic, so `two_tone_vs_flux` no longer refits a poor trace up to 20 times.
