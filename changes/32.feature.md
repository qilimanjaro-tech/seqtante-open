Added the `CalibrationNode` base and the experiment registry (ADR-0004). This is the first slice of the node base (task 5); the operating-point helper, the restore context manager and the three-phase lifecycle follow in later PRs, and the graph build that drives the nodes is QHC-1800.

- **`NODE_REGISTRY`** replaces `experiment_functions_dict` as the one registry of experiments. A `CalibrationNode` subclass registers itself through `__init_subclass__` from its `experiment` name, declaring the analyses it supports; the parser reads the registry to validate a step's `experiment` and `analysis`. The four experiments still written as functions, and those with no implementation yet, stay as declarations the registry seeds, so a tree that names them still parses while they are ported (ADR-0007). `experiment_specs` keeps re-exporting `experiment_spec`/`known_experiments` from the registry.
- **`CalibrationNode`** is now the abstract base every experiment subclasses. It carries the class-level declarations (`experiment`, `analyses`, `applies_operating_point`, `parallel`) and the graph contract (`idx`, `name`, `run`); the mid-level spines set no `experiment` and are not registered.
- **`RunContext`** carries the platform, the runcard path and the one `Calibration` a run reads, so a run deserialises the calibration once and hands the same object to every node (ADR-0001).
- New `--calibration_path` CLI argument; the tree may still set the path.
