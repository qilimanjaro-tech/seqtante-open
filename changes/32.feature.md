Added the `CalibrationNode` base and the experiment registry (ADR-0004). This is the first slice of the node base (task 5); the operating-point helper, the restore context manager and the three-phase lifecycle follow in later PRs, and the graph build that drives the nodes is QHC-1800.

- **`NODE_REGISTRY`** replaces `experiment_functions_dict` as the one registry of experiments. A `CalibrationNode` subclass registers itself through `__init_subclass__` from its `experiment` name, declaring the analyses it supports and, for a benchmark, how it reports its value (unit and direction). The parser reads the registry to validate a step's `experiment` and `analysis` and to convert its thresholds to the benchmark's unit (ADR-0002). The four experiments still written as functions, and those with no implementation yet, stay as declarations the registry seeds, so a tree that names them still parses while they are ported (ADR-0007). The old `experiment_specs` module is removed; the parser imports the registry directly.
- **`CalibrationNode`** is the base every experiment subclasses. It carries the class-level declarations (`experiment`, `analyses`, `applies_operating_point`, `parallel`, `benchmark`) and the graph contract (`idx`, `name`, `run`); the mid-level spines set no `experiment` and are not registered. `run` is a concrete stub on the base that raises until the three-phase lifecycle lands (task 5c).
- **`RunContext`** carries the platform, the runcard path and the one `Calibration` a run reads, so a run deserialises the calibration once and hands the same object to every node (ADR-0001).
