Added the calibration-file model: operating points per target, named pulses and experiment sections (ADR-0001). It replaces the temporary operating-point format and is the contract qili-experiments and qili-runtime read, so it is a one-way door.

A new package `seqtante_open.calibration`:

- **`bus_alias`** — the one place that maps `(target, line[, axis])` to a qililab bus alias (ADR-0008): drive/readout are `<line>_<target>`, flux is target-first with the axis last (`flux_q14_z`), so crosstalk calibration and the bus sorter keep working. `experiments.utils.flux_buses` now builds on it, so bus names have a single source.
- **`pulses.parse_pulse_name`** — the pulse-name grammar: a `lower_snake` purpose with the operating point as a `-`-joined suffix (`readout-reset`, `pi-reset`).
- **`model`** — the pydantic model. `OperatingPoint` holds `flux` (a plain measured bias, ADR-0010), the neighbours it parks in `parked_flux` (ADR-0009), and `drive`/`readout` frequencies; `readout.levels` tags the |0>/|1> levels with the readout pulse they were taken with (D8). A section names its `operating_point` and the pulses it plays by name. Unknown keys are rejected.
- **`io`** — reads and writes the model from a qililab `Calibration` (operating points in `Calibration.parameters`, pulses in `Calibration.waveforms`), persisted with `serialize_to` / `deserialize_from`. Reading checks that every pulse a section names exists on its bus; `readout_levels_for` refuses readout levels taken with a different pulse than the consumer plays (D8).
- **`seed`** — `seed_calibration` assembles a fresh `Calibration` from the experimentalists' manual numbers (operating points + sections and the named pulses), validating that the pulses the sections reference are present. No migration from the old QHC-1608 format.

## **Example**
```yml
operating_points_version: 1
operating_points:
  q14:
    reset:
      flux: {z: 0.615, x: 0.27}
      parked_flux: {c13_14: {z: 0.02}, c14_15: {z: -0.01}}
      drive:   {lo: 2.9e9,  if: -100e6}
      readout:
        lo: 6.38e9
        if: 63.4e6
        attenuation: 48
        levels:
          pulse: readout-reset
          level_0: {nominal: 0.0, std: 0.01}
          level_1: {nominal: 1.0, std: 0.02}
experiments:
  rabi:
    q14: {operating_point: reset, pulses: {readout: readout-reset, drive: pi-reset}}
```
