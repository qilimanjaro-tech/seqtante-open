Added the calibration file: operating points per target, named pulses and experiment sections (ADR-0001). It replaces the temporary operating-point format and is the contract qili-experiments and qili-runtime read, so it is a one-way door. seqtante-open reads and writes it through `qili_qprograms.calibration`, the same module the qili-qprograms QPrograms read it with.

- **Operating points** — `OperatingPoint` holds `flux` (a plain measured bias, ADR-0011; `Flux.on(axis)` reads the bias on `z` or `x`), the neighbours it parks in `parked_flux` (ADR-0010), and `drive`/`readout` frequencies; `readout.levels` tags the |0>/|1> levels with the readout pulse they were taken with (D8).
- **Experiment sections** — under `experiments.<experiment>`, a target's section names its `operating_point` and the pulses it plays by name; any other key under the experiment is an experiment-wide setting, and a section keeps extra keys for the consumer that reads them. Target keys are validated (`q<n>`, `c<n>_<m>` with `n < m`); everywhere else unknown keys are rejected, so a typo fails the read.
- **Pulse names** — a `lower_snake` purpose with the operating point as a `-`-joined suffix (`readout-reset`, `pi-reset`). Pulses live in `Calibration.waveforms`, operating points and sections in `Calibration.parameters`; reading the file checks that every pulse a section names exists on its bus, and `readout_levels_for` refuses readout levels taken with a different pulse than the consumer plays (D8).
- **Bus aliases** — drive/readout are `<line>_<target>`, flux is axis-first (`flux_z_q14`), following qililab's flux bus naming, so crosstalk calibration and the bus sorter keep working (ADR-0008).
- **Seeding** — `seed_calibration` assembles a fresh `Calibration` from the experimentalists' manual numbers (operating points, sections and the named pulses). No migration from the old QHC-1608 format.

### **Example**
```yml
operating_points_version: 1
operating_points:
  q14:
    reset:
      flux: {z: 0.615, x: 0.27}
      parked_flux: {c13_14: {z: 0.02}, c14_15: {z: -0.01}}
      drive:   {lo: 2.9e9,  if: -100e6}
      readout:
        lo: 6.38e9
        if: 63.4e6
        attenuation: 48
        levels:
          pulse: readout-reset
          level_0: {nominal: 0.0, std: 0.01}
          level_1: {nominal: 1.0, std: 0.02}
experiments:
  rabi:
    q14: {operating_point: reset, pulses: {readout: readout-reset, drive: pi-reset}}
```
