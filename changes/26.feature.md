Added `seqtante_open.targets`: experiment targets as objects instead of strings. Nothing uses them yet.

- `QubitTarget(qubit_id)` and `CouplerTarget(qubit_id_1, qubit_id_2)`, frozen subclasses of `ExperimentTarget` with a `kind` field (`"qubit"` / `"coupler"`), print as `q14` and `c2_3`. `Target` is their union, for annotations.
- A target equals its name and hashes like it, so `QubitTarget(14) == "q14"` and a target and its name find each other as dict keys. Type checkers don't know about this, so typed code looks up with a target.
- `ExperimentTarget.from_str` parses `q<n>` and `c<n>_<m>` with `n < m` and no leading zeros, and raises a `ValueError` for anything else, including `q01`, `c2_1`, `c1_1` and non-strings.
- `CouplerTarget.between(a, b)` builds the coupler between two qubits given in either order, as the runcard's topology lists them.
