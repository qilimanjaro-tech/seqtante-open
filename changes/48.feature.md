Added the `landau_zener` benchmark node (delivery task 11, QHC-1808), porting the compartmentalized Landau-Zener experiment (QHC-1822). It biases the slow flux lines to the operating point, runs the sweep with the idle DC flux and readout frequencies from the calibration and the annealing paths/times, ramp durations and AC crosstalk matrix from the tree, and normalises the measured signal to a transition probability with the reset-point readout levels (refusing levels taken with a different readout pulse, ADR-0001 D8). It writes nothing, as a benchmark does. The benchmark is left "Not evaluated" for now: the agreement metric and theory curve that give it a verdict are a follow-up (QHC-1921).

- **`seqtante_open.experiments.qprogram.annealing`** — the compartmentalized LZ QProgram builders (Square holds, Arbitrary ramps, the 16384-sample Qblox sequencer guard, a caller-supplied AC `CrosstalkMatrix`).
- **`seqtante_open.experiments.experiment_classes.lz_transition_not_idling_reset__custom_linear_ramp`** — the execution driver, which builds every QProgram up front and streams the readout quadratures and single-shot threshold.
- **`seqtante_open.experiments.fitting.LandauZenerFit`** — normalises the rotated signal to a transition probability with the readout levels and plots it (no model fit yet).
