Added the `landau_zener` benchmark node (delivery task 11, QHC-1808). It runs the compartmentalized Landau-Zener sequence with the shared `generalized_linear_ramps` QProgram from `qili-qprograms` (SDK-402), one QProgram per flux path in the step's `flux_paths`, and normalises the measured signal to a transition probability with the operating point's readout levels (refusing levels taken with a different readout pulse, ADR-0001 D8). It writes nothing, as a benchmark does. The benchmark is left "Not evaluated" for now: the agreement metric and theory curve that give it a verdict are a follow-up (QHC-1921).

- The base biases the slow flux lines to the step's operating point, which is the idle point and the readout point; `reset_point` names the operating point held at the start of each repetition (the step's own by default). The tree sets `flux_paths`, `annealing_times`, `relax_duration`, `averages`, the entry/exit ramp durations and move orders, and `readout_ringup_time`.
- The fast-flux levels are corrected for AC crosstalk by qililab when it compiles: with the step's `ac_crosstalk` (a raw 2x2 array, as on BSC) set as `crosstalk_matrix_ac` on a copy of the calibration, or else the calibration's own `crosstalk_matrix_ac`. A step with neither, or with non-zero flux offsets on the fast-flux buses, fails the target before anything is measured.
- **`CalibrationNode._set_readout_line`** — sets the readout LO and attenuation at the operating point, for a node that plays no drive; `_set_operating_point_hardware` now calls it.
- **`seqtante_open.experiments.fitting.LandauZenerFit`** — normalises the rotated signal to a transition probability with the readout levels and plots it (no model fit yet).
