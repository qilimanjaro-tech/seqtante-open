The `node_types` / `pipelines` tree format is gone, and trees written in it no longer load. This lands on the delivery branch, where nothing is deployed, and the run is wired back up by later tasks.

- `overwrites` is replaced by `overrides`, with the same list shape. `simultaneous` is removed, since no fluxonium experiment runs in parallel.
- Experiment variants written as `<experiment>-<suffix>` are replaced by named steps.
- The parser no longer builds `CalibrationNode`s, so a run parses the tree but measures nothing until the graph is built from the pipelines (QHC-1800).
- The parser no longer computes `data_folder` or passes the top-level `calibration_path` to each experiment, and `data_folder` cannot be set from the tree. The legacy nodes read both, so they fail until the node base provides them.
