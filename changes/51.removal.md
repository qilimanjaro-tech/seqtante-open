Removed seqtante-open's own copy of the calibration-file module. It is now imported from qili-qprograms, whose QPrograms read the same file.

- `seqtante_open.calibration` (`model`, `io`, `pulses`, `bus_alias`, `seed`) and `seqtante_open.targets` are gone. Import from `qili_qprograms.calibration`, `qili_qprograms.bus_alias` and `qili_qprograms.targets` instead.
- What qili-qprograms' version adds now applies here: experiment-wide keys under `experiments.<experiment>`, `section_bus` for flux pulses, `pulse_name`, `fullmatch` for pulse names, and `Flux.on(axis)`. Flux axes are qili's `Axis` (`"x"` or `"z"`), so a `y` axis is no longer accepted.
- `qili-qprograms` is bumped to `0.0.2.dev14+ge85237f`.
