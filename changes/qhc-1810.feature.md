Added the PDF report, built in-process at the end of a run behind the optional `seqtante_open[report]` install extra (ADR-0009). Running calibrations never pulls in the report dependencies, and a missing extra logs a warning naming `pip install "seqtante_open[report]"` and lets the run finish normally — the database entry and the calibration file are already saved before the report is attempted.

- **`seqtante_open.report`** — a separate, lazily-imported module (never imported by `outputs`) that renders a run's in-memory results to a PDF with reportlab: a header with the timestamp, Seqtante-Open and qililab versions and the run id; the benchmark table (value ± σ, verdict, and the threshold with its unit and direction); the steps that failed or were skipped with the reason; and a per-target section with operating points before and after, fit plots and the reset-point move log.
- **`seqtante_open.run_results.RunResults`** — the in-memory record the run collects and the report reads, carrying no PDF dependency. The run populates the timestamp, versions, run id and the failed/skipped steps now; benchmark results, operating points and fit plots join the same record as the experiment nodes are ported (tasks 6–12).
- **`--no-report`** turns the report off for quick debugging runs; with it off the report module is never imported, so the run does not need the extra installed at all.
