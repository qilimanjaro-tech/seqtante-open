Removed the file summary of calibrated parameters, replaced by saving the fitting results to the database.

- The `storage.calibration_data` key (`file_path`, `file_type`) is no longer read, and the summary file is no longer written at the end of a calibration run. A config that still sets it is not rejected; the key is ignored.
- Removed `CalibrationData`, `CalibrationDataConf`, `Outputs.store_parameter` and the `Outputs.calibration_data` property. `CalibrationParameter` is replaced by `FittedParameter`, whose fidelity keys are `gate_fidelity_1q` and `gate_fidelity_2q` instead of `1q_gate_fidelity` and `2q_gate_fidelity`.
