Added a `Tests` workflow: the suite runs on 3.11 and 3.13 for a pull request, fills in 3.12 on
`main`, and measures coverage on 3.13. Dependencies are installed from CodeArtifact through the
`qilimanjaro` index with a short-lived OIDC token.

Test-suite maintenance, no change to the package:

- The node tests built their stand-in `Calibration` as a `SimpleNamespace`, which stopped
  carrying what the nodes need once they began stamping a per-measurement `data_folder` into a
  copy of it. They use a real `Calibration` now, and assert that every measurement gets its own
  stamped copy while the shared one is left untouched.
- `FluxoniumTwoToneModel` had no `FittingTestCase`, which `test_registry` fails on. Added one, a
  qubit peak at a known IF.
- `SEED` seeds the global `numpy` RNG just before `fit()`, as well as the `DATA` builder. The
  Lorentzian fits run `differential_evolution`, which draws its population from that RNG, so an
  unseeded fit answered differently depending on what ran before it. Seeded there rather than
  inside `lorentzian_fit`, because `FluxoniumTwoToneFluxModel.fit` retries a poor trace by
  fitting it again, which only works while consecutive fits differ. See
  `tests/experiments/fitting/README.md`.
